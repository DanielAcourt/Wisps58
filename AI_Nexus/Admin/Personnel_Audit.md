## 6. Epistemic Profile

The research methodology enforces strict epistemic separation across all operations:

$$ \text{Observation} \neq \text{Interpretation} \neq \text{Hypothesis} \neq \text{Evidence} \neq \text{Authority} \neq \text{Physical Truth} $$

- **Telemetry vs Physical Truth:** A recorded sensor value is evidence of what the sensor reported, not proof that the physical environment is in that state.
- **LLM Output vs Truth:** Generated text is evidence of model inference, not proof of factual correctness or authority.
- **Passing Test vs Theory:** An implementation passing unit tests is evidence that the code meets test conditions, not proof of the underlying theoretical framework.

