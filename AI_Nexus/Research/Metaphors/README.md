# Metaphorical Principles: The Language of Systems

## 🌀 Purpose
Because the Technical Lead (Daniel Acourt) thinks in **Volumes and Space** rather than linear language, he frequently uses complex metaphors to describe systemic problems. This directory serves to "stabilize" these metaphors into **Operational Principles**.

## 🛠 The Translation Process
1.  **Metaphor:** The raw, spatial image used to describe a problem (e.g., "The Elephant in the Room").
2.  **Principle:** The core technical or philosophical rule derived from the metaphor (e.g., "Address the gap between vision and legacy code").
3.  **Application:** How this principle is applied to the codebase or delegation SOP.

## 🤝 Community & AI Alignment
By codifying these metaphors, we ensure that agents (Jules/Claude) can interpret the Lead's day-to-day language with 100% accuracy, even when the specific technical "How" is still being discovered through experiment and testing.
