# Mathematics & Algorithms

This directory stores the mathematical foundations of the Sovereign Framework, including:
- **PSTA Method**: Probabilistic Spatio-Temporal Analysis for autonomous decision making.
- **Simulation Physics**: Formulae for environmental telemetry mapping.
- **Procedural Generation**: Algorithms for runtime reconstruction of spatial data.
