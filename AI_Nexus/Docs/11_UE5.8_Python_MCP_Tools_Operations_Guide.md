## ⚙️ 2. Core Execution Mechanics & Rules

### Rule 1: Embedded Runtime Isolation
The `unreal` C++ Python module **only exists inside Unreal Engine's active process**.
- **Inside Unreal Engine (Output Log -> Python)**: `import unreal` succeeds immediately.
- **Outside Unreal Engine (System Terminal / PowerShell)**: Running `python -c "import sovereign_mcp_tools"` directly will raise `ModuleNotFoundError: No module named 'unreal'`. This is normal and expected behavior.

### Rule 2: Startup Initialization (`init_unreal.py`)
Unreal Engine automatically executes `/WispsCPPVR/Content/Python/init_unreal.py` upon plugin startup.
This script initializes `sovereign_mcp_tools` and prints system readiness telemetry to the Unreal Output Log.

## 🐍 3. Spawning & Tag Automation API (`sovereign_mcp_tools.py`)

### `spawn_actor_with_tags(...)`
Spawns an actor into the active level level, sets a visible Static Mesh asset, populates `Actor.tags` and `GameplayTags`, and highlights the actor in the World Outliner.

#### Signature:
```python
def spawn_actor_with_tags(
    class_path: str = "/Script/Engine.StaticMeshActor",
    location: list = None,          # [X, Y, Z] e.g. [0, 0, 200]
    rotation: list = None,          # [Pitch, Yaw, Roll] e.g. [0, 0, 0]
    actor_tags: str = "",          # Comma-separated tags e.g. "TagA,TagB"
    gameplay_tags: str = "",       # Comma-separated gameplay tags e.g. "Sovereign.Entity"
    mesh_path: str = "/Engine/BasicShapes/Cube.Cube"
) -> unreal.Actor
```

## 💻 4. Command Reference & How-To Guide

### A. Executing directly inside Unreal Engine Output Log
1. Open Unreal Engine 5.8.1.
2. Open **Window -> Output Log**.
3. Switch the bottom left dropdown from **`Cmd`** to **`Python`**.
4. Paste and press **Enter**:
```python
import sovereign_mcp_tools; sovereign_mcp_tools.spawn_actor_with_tags('/Script/Engine.StaticMeshActor', [0, 0, 200], [0, 0, 0], 'PlayerSpawn,WispCore', 'Sovereign.Entity')
```

---

### B. Executing via PowerShell REST Calls (`bridge.py`)

#### 1. Start the Bridge (`bridge.py`)
```powershell
cd "Sovereign_Intelligence/IronOfficer"
python bridge.py
```

#### 2. Initialize MCP Handshake
```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/v1/mcp/initialize" -Method Post
```

#### 3. Fetch Discovered Tools
```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/v1/mcp/tools" -Method Get
```

#### 4. Spawn Actor & Assign Tags via HTTP Payload
```powershell
$body = @{
    tool_name = "spawn_actor_with_tags"
    tool_args = @{
        class_path = "/Script/Engine.StaticMeshActor"
        location = @(100, 100, 300)
        rotation = @(0, 45, 0)
        actor_tags = "McpActor,WispCore"
        gameplay_tags = "Sovereign.Saveable"
        mesh_path = "/Engine/BasicShapes/Cube.Cube"
    }
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://127.0.0.1:8000/v1/mcp/call" -Method Post -Body $body -ContentType "application/json"
```

## 🚀 5. Extending & Adding New Tools

To add a new editor automation tool:

1. Open `/WispsCPPVR/Content/Python/sovereign_mcp_tools.py`.
2. Define your function using standard `unreal` API calls:
```python
def my_custom_tool(param1: str):
    unreal.log(f"Executing custom tool with {param1}")
    # Perform editor manipulation...
```
3. Expose it on `SovereignEditorToolLibrary`:
```python
class SovereignEditorToolLibrary:
    spawn_actor_with_tags = staticmethod(spawn_actor_with_tags)
    my_custom_tool = staticmethod(my_custom_tool)
```
4. Save the file. In Unreal Engine Output Log (Python mode), run:
```python
import importlib, sovereign_mcp_tools; importlib.reload(sovereign_mcp_tools)
```
Your new tool is immediately live!
