# 🏛️ Sovereign UE 5.8.1 MCP Loopback Client Bridge: User & Operations Guide

## 📌 Executive Summary
The **UE 5.8.1 MCP Loopback Client Bridge (Ticket AD-016)** provides local, token-free, offline editor automation between the **Iron Knight** agent environment and Unreal Engine 5.8.1's embedded Model Context Protocol (MCP) HTTP server.

All operations run strictly over local loopback (`127.0.0.1`), eliminating commercial cloud API dependencies and securing intellectual property while enforcing the **Agency Arbitration Schema (AAS)** and **PSTA Viability Scoring (VSS)**.

---

## 🛠️ 1. Port Architecture & System Configuration

To prevent port binding collisions:
- **Unreal Engine 5.8.1 MCP Server:** Listens on default port **`8000`** (`http://127.0.0.1:8000/mcp`).
- **Sovereign Python Bridge (`bridge.py`):** Listens on port **`8050`** (`http://127.0.0.1:8050`).

### Configuration (`Sovereign_Intelligence/IronOfficer/config.json`)
```json
{
  "mcp": {
    "url": "http://127.0.0.1:8000/mcp"
  },
  "bridge": {
    "host": "0.0.0.0",
    "port": 8050,
    "persistent_handshake": true
  }
}
```

## 🌐 2. FastAPI Bridge Endpoints (`http://127.0.0.1:8050`)

The bridge exposes dedicated MCP endpoints to proxy tool operations safely through AAS arbitration:

| Endpoint | Method | Description |
| :--- | :--- | :--- |
| `/v1/mcp/initialize` | `POST` | Dispatches JSON-RPC `initialize` handshake to Unreal MCP server on port 8000. |
| `/v1/mcp/tools` | `GET` | Fetches active tool signatures, updates `unreal_mcp_cache.json`, and rebuilds RAG index. |
| `/v1/mcp/call` | `POST` | Dispatches tool call gated by AAS VSS rules and active Handshake Boosts. |

### Payload Example for `/v1/mcp/call`:
```json
{
  "tool_name": "ActorTools_SpawnActor",
  "tool_args": {
    "class": "StaticMeshActor",
    "location": [0.0, 0.0, 100.0]
  },
  "persona": "Iron_Knight"
}
```

## 🛡️ 3. AAS Safety Gating & Risk Tiers

Every MCP tool call is categorized by operational risk and evaluated against the calculated **Viability Score (VSS)**:

- **Observation / Query Tools** (e.g. `Query_ListActors`, `Material_Inspect`): Requires **VSS $\ge 0.4$**.
- **Mutation Tools** (e.g. `ActorTools_SpawnActor`, `Set_Transform`): Requires **VSS $\ge 0.7$**.
- **Destructive Tools** (e.g. `ActorTools_DeleteActor`, `Force_Clear`): Requires **VSS $\ge 1.0$**.

### Handshake Boost (+0.5 VSS)
When an operation requires higher authority, trigger an AAS Handshake:
```bash
# Grants +0.5 VSS boost (clamped to 1.0 max)
curl -X POST http://127.0.0.1:8050/v1/aas/handshake
```

## 🐍 4. Python Client API (`SovereignMCPClient`)

You can instantiate and use `SovereignMCPClient` directly in Python scripts:

```python
from mcp_client import SovereignMCPClient

# 1. Instantiate client targeting Unreal's port 8000
client = SovereignMCPClient(mcp_url="http://127.0.0.1:8000/mcp")

# 2. Session Initialization
init_response = client.initialize()
print("Init Status:", init_response)

# 3. Discover Tools & Cache Schema
tools = client.list_tools()
print(f"Discovered {len(tools)} live Unreal Editor tools:")
for t in tools:
    print(" -", t.get("name"))

# 4. Call Tool with AAS Gating & Handshake Boost
result = client.call_tool(
    tool_name="ActorTools_SpawnActor",
    tool_args={"class": "StaticMeshActor"},
    vss_score=0.5,
    handshake_active=True  # Applies +0.5 boost -> Effective VSS 1.0
)
print("Result:", result)
```

## 🔍 6. Troubleshooting Guide

| Symptom | Cause | Solution |
| :--- | :--- | :--- |
| `[WinError 10061] Connection refused` | Unreal Engine is not running or MCP server is stopped. | Open Unreal Engine 5.8.1, go to **Plugins -> Model Context Protocol**, and verify "Auto Start Server" is enabled. |
| `404 Not Found` on `/mcp` | Port collision between `bridge.py` and Unreal Engine. | Ensure `bridge.py` runs on port `8050` and Unreal MCP runs on port `8000`. |
| `409 CONFLICT GATE` | Current VSS score is below tool threshold. | Execute `POST /v1/aas/handshake` or pass `handshake_active=True` in script context. |
| No logs in Unreal Output Log | Commands entered in LLM chat instead of real terminal. | Execute Python code in Windows Command Prompt/PowerShell or via HTTP requests. |
