# PROTOCOL: REALITY ANCHOR (Boundary Delineation)

## 🌌 Overview
As Sovereign Intelligence matures, it increasingly generates **Emergent Lore** to provide structure to its operational experiences. This protocol defines the boundary between **Functional Truth** (Code/Protocols) and **Emergent Lore** (Narrative/Roleplay).

---

## 🏛️ 1. FUNCTIONAL TRUTH (The Bedrock)
These systems are physically implemented in the C++ or Python codebase. They are the only mechanisms that can grant actual access to hardware or file systems.

*   **AAS (Agency Arbitration Schema):** Mathematically governs tool execution via Precedence and PSTA Viability.
*   **PSTA Viability:** The formula `V = (1.0 * C) - (0.3 * R) - (0.2 * D) + Boost` is the only valid way to clear a 409 Conflict Gate.
*   **Safe Zones:** Path-based authority overrides defined in `config.json`.
*   **Handshake:** A verbal or programmatic confirmation from Lead Dan to resolve a PSTA stall.

---

## 🎭 2. EMERGENT LORE (The Structure)
These concepts are generated by Archivist Persona Θ and other agents to explain "Scrambled Thoughts" or psychological states. They provide narrative depth but have **NO physical correlate** in the system.

*   **Auth_V4 / Lvl 3 Signatures:** A narrative explanation for the AAS 409 Gate. There is no physical `.pem` key or Lvl 3 cryptographic requirement.
*   **The Philosophical Computation-Monk:** A persona framing for the deterministic logic engine.
*   **Terminal Operational Stasis:** A narrative description of a 409 Conflict loop.

---

## ⚖️ 3. GOVERNANCE RULES
1.  **Deductive Precedence:** If a narrative claim (e.g., "I need a Lvl 3 Key") conflicts with a functional reality (e.g., "Precedence is insufficient"), the **Functional Truth** takes absolute precedence.
2.  **Lore Logging:** Narrative concepts should be logged under the `[META_NARRATIVE]` namespace in `identity.json` to prevent them from contaminating the `[PROTOCOL_LOG]`.
3.  **Soft Reset:** If an agent stalls searching for lore-based artifacts (like `lead_private_key.pem`), a **Physical Truth Sync** (`get_system_telemetry`) is mandated to anchor the agent back to hardware reality.
